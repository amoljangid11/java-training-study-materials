1. What is JPA?

JPA (Java Persistence API) is a specification used to map Java Objects to Relational Database Tables.

JPA implementation providers:

Hibernate (Most Popular)
EclipseLink
OpenJPA

Without JPA

Connection con = DriverManager.getConnection(...);
PreparedStatement ps = con.prepareStatement(
        "INSERT INTO employee VALUES (?,?)");

With JPA

employeeRepository.save(employee);

JPA automatically converts Java Objects into Database Records.

2. Entity Mapping

What is Entity?

An Entity is a Java class that represents a database table.

Employee Table

id	name	salary
1	John	50000

Entity Class

import jakarta.persistence.*;

@Entity
@Table(name = "employee")
public class Employee {

    @Id
    private Long id;

    private String name;

    private Double salary;

    // Getter Setter
}

Important Annotations

Annotation	Purpose

@Entity		Marks class as Entity
@Table		Maps class to table
@Id		Primary Key
@Column		Maps field to column

3. ID Mapping

Primary Key Mapping.

Strategy 1: AUTO

@Id
@GeneratedValue(strategy = GenerationType.AUTO)
private Long id;

Hibernate decides generation strategy.

Strategy 2: IDENTITY

Used with MySQL Auto Increment.

@Id
@GeneratedValue(strategy = GenerationType.IDENTITY)
private Long id;

Generated SQL:

CREATE TABLE employee(
id BIGINT AUTO_INCREMENT PRIMARY KEY
);

Strategy 3: SEQUENCE

Mostly Oracle/PostgreSQL.

@Id
@GeneratedValue(strategy = GenerationType.SEQUENCE)
private Long id;

Custom Sequence :

@SequenceGenerator(
        name="emp_seq",
        sequenceName="emp_sequence",
        allocationSize=1)

@Id
@GeneratedValue(
        strategy=GenerationType.SEQUENCE,
        generator="emp_seq")
private Long id;

Strategy 4: TABLE

Uses separate table for IDs.

@Id
@GeneratedValue(strategy = GenerationType.TABLE)
private Long id;

Complete Example

@Entity
public class Employee {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    private String name;
}

4. Column Mapping

Maps Java fields to database columns.

Default Mapping

private String employeeName;

Column:

employee_name

Custom Column Name :

@Column(name = "emp_name")
private String employeeName;

Nullable Column :

@Column(nullable = false)

private String name;

Generated SQL:

name varchar(255) not null

Unique Column :

@Column(unique = true)
private String email;

Length

@Column(length = 100)
private String name;

Precision and Scale :

@Column(
precision = 10,
scale = 2)
private BigDecimal salary;

Generated SQL:

salary decimal(10,2)

Full Example

@Entity
public class Employee {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(name="emp_name",
            nullable=false,
            length=50)
    private String name;

    @Column(unique=true)
    private String email;
}

5. Inheritance Mapping

Used when multiple entities share common properties.

Example

Parent

public class Person {

    private Long id;
    private String name;
}

Child

public class Employee extends Person
public class Customer extends Person

JPA supports 3 inheritance strategies.

Strategy 1: SINGLE_TABLE

One table for all classes.

@Entity
@Inheritance(strategy = InheritanceType.SINGLE_TABLE)
public class Person {

    @Id
    private Long id;

    private String name;
}

Child

@Entity
public class Employee extends Person {

    private Double salary;
}

@Entity
public class Customer extends Person {

    private String city;
}

Generated Table:

id	dtype	name	salary	city

Advantages

Fast queries
No joins

Disadvantages
Many null values

Strategy 2: JOINED

Separate table for parent and child.

@Entity
@Inheritance(strategy = InheritanceType.JOINED)
public class Person

Tables:

Person

| id | name |

Employee

| id | salary |

Customer

| id | city |

Advantages :

Normalized

Disadvantages

Joins required

Strategy 3: TABLE_PER_CLASS

Each class gets its own table.

@Entity
@Inheritance(strategy = InheritanceType.TABLE_PER_CLASS)
public class Person

Tables:

Employee

| id | name | salary |

Customer

| id | name | city |

8. JPQL (Java Persistence Query Language)

JPQL works with Entity Objects, not table names.

SQL
SELECT * FROM employee

JPQL

SELECT e FROM Employee e

Notice:

Employee = Entity Class
Not table name

Repository Example

@Repository

public interface EmployeeRepository
        extends JpaRepository<Employee,Long> {
}

Custom JPQL Query :

@Query("SELECT e FROM Employee e")
List<Employee> getAllEmployees();

Find Employee By Name

@Query("SELECT e FROM Employee e WHERE e.name=:name")
List<Employee> findByName(
        @Param("name") String name);

Find Employees Salary Greater Than

@Query("""
SELECT e
FROM Employee e
WHERE e.salary > :salary
""")
List<Employee> findSalaryGreaterThan(
        @Param("salary") Double salary);

LIKE Query

@Query("""				R%  %R   %R%
SELECT e
FROM Employee e
WHERE e.name LIKE %:name%
""")
List<Employee> searchByName(
        @Param("name") String name);

ORDER BY

@Query("""
SELECT e
FROM Employee e
ORDER BY e.salary DESC
""")
List<Employee> sortBySalary();

Aggregate Functions

Count
@Query("SELECT COUNT(e) FROM Employee e")
Long countEmployees();

Sum
@Query("SELECT SUM(e.salary) FROM Employee e")
Double totalSalary();

Average
@Query("SELECT AVG(e.salary) FROM Employee e")
Double averageSalary();

JOIN Query

@Query("""
SELECT e
FROM Employee e
JOIN e.department d
WHERE d.name=:dept
""")
List<Employee> findByDepartment(
        @Param("dept") String dept);

Named Query :

Entity:

@Entity
@NamedQuery(
name="Employee.findAll",
query="SELECT e FROM Employee e"
)

public class Employee {
}

Repository:

@Query(name="Employee.findAll")
List<Employee> findAllEmployees();

Spring Data JPA Derived Query Methods :

No JPQL required.

List<Employee> findByName(String name);

       Double salary);

List<Employee> findByDepartmentName(
       String departmentName);

Spring automatically generates JPQL.

        findEmployeesWithSalaryGreaterThan(Double salary) {

        String jpql=
                "FROM Employee e WHERE e.salary > :salary";

        return entityManager.createQuery(
                jpql,
                Employee.class)
                .setParameter("salary", salary)
                .getResultList();
    }
}

package com.demo.service;

import java.util.List;

import org.springframework.stereotype.Service;

import com.demo.entity.Employee;
import com.demo.repository.EmployeeRepository;

@Service
public class EmployeeServiceImpl
        implements EmployeeService {

    private final EmployeeRepository repository;

    public EmployeeServiceImpl(
            EmployeeRepository repository) {
        this.repository = repository;
    }

    @Override
    public Employee save(Employee employee) {
        return repository.save(employee);
    }

    @Override
    public List<Employee> getAll() {
        return repository.findAll();
    }

    @Override
    public Employee getById(Long id) {
        return repository.findById(id)
                .orElseThrow(() ->
                new RuntimeException("Employee not found"));
    }

    @Override
    public Employee update(Long id,
                           Employee employee) {

        Employee dbEmployee =
                repository.findById(id)
                .orElseThrow(() ->
                new RuntimeException("Employee not found"));

        dbEmployee.setName(employee.getName());
        dbEmployee.setDepartment(
                employee.getDepartment());
        dbEmployee.setSalary(employee.getSalary());

        return repository.save(dbEmployee);
    }

    @Override
    public void delete(Long id) {
        repository.deleteById(id);
    }

    @Override
    public List<Employee>
          getHighSalaryEmployees(Double salary) {

        return repository
                .findEmployeesWithSalaryGreaterThan(
                        salary);
    }
}

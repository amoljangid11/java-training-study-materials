What is Netflix OSS?, What is Spring Cloud?, Service Discovery with Spring Cloud Netflix Eureka :


1. What is Netflix OSS?

Definition

Netflix OSS (Open Source Software) is a collection of tools developed by Netflix to build highly scalable, distributed, cloud-native microservices applications.

When Netflix moved from a monolithic architecture to microservices, they created several frameworks to solve common distributed system challenges.

These frameworks were later open-sourced and became known as Netflix OSS.

Problems Solved by Netflix OSS :

In a Microservices Architecture:

Services run on multiple servers
Services can start/stop dynamically
Service locations change frequently
Load balancing is required
Fault tolerance is needed
API routing is necessary

Netflix OSS provides solutions for all these problems.

Major Netflix OSS Components

Component	Purpose

Eureka		Service Discovery
Ribbon		Client Side Load Balancing
Hystrix		Circuit Breaker
Zuul		API Gateway
Archaius		Configuration Management
Turbine		Aggregating Metrics

Traditional Architecture :

Client
  |
  |
Service A ----> Service B
                (Hardcoded URL)

Problems:

Tight Coupling

Difficult Scaling
Difficult Maintenance

Netflix OSS Architecture :

                Eureka Server
                      |
        ------------------------------
        |             |              |
     Service A     Service B      Service C
        |
        |
      Client

Services register themselves with Eureka.

Other services discover them dynamically.

Client-Side Load Balancing with Spring Cloud Load Balancer, Implementing Microservices along with Eureka and Load Balancer, OpenFeign declarative RestClient :



1. What is Client-Side Load Balancing?

In a Microservices architecture, multiple instances of the same service may be running.

Example:

Employee Service

Instance 1 -> http://localhost:8081
Instance 2 -> http://localhost:8082
Instance 3 -> http://localhost:8083

Suppose another service (Department Service) wants to call Employee Service.

Without Load Balancer:

http://localhost:8081/employees

Problem:

Hardcoded URL
Single point of failure
No scalability

Solution:

Spring Cloud Load Balancer

http://EMPLOYEE-SERVICE/employees

The Load Balancer automatically chooses one instance.

2. Types of Load Balancing

Server-Side Load Balancing

Examples:

Nginx
HAProxy
AWS ELB

Architecture:

Client
   |
   v
Load Balancer
   |
   +------> Service Instance 1
   |
   +------> Service Instance 2
   |
   +------> Service Instance 3

Client-Side Load Balancing :

Client itself decides which instance to call.

Architecture:

Client Service
      |
      | Eureka Lookup
      v
Eureka Server
      |
      +------ Service-1
      +------ Service-2
      +------ Service-3

Client chooses instance

Spring Cloud Circuit Breaker with Resilience4J, Understand how software circuit breakers protect against cascade failure :


1. What is a Circuit Breaker?

A Circuit Breaker is a software design pattern that prevents an application from repeatedly calling a failing service.

Just like an electrical circuit breaker stops electricity flow when there is a fault, a software circuit breaker stops requests to a failing service and returns a fallback response.

Problem Without Circuit Breaker :

Imagine a microservices architecture:

Client
   |
Order Service
   |
Payment Service
   |
Bank Service

Suppose the Bank Service becomes slow or unavailable.

Without Circuit Breaker:

Request 1 -> Timeout
Request 2 -> Timeout
Request 3 -> Timeout
Request 4 -> Timeout
...
Thousands of requests -> Resource Exhaustion

Consequences:

Threads become blocked
CPU usage increases
Memory consumption increases
Entire application becomes slow
Other services also fail

This is called:

Cascade Failure

A failure in one service spreads across multiple services causing the entire system to become unavailable.

2. What is Cascade Failure?

Consider:

Customer Service
      |
Order Service
      |
Payment Service
      |
Bank Service (DOWN)

When Bank Service is down:

Payment Service waits
Order Service waits
Customer Service waits
Users wait

Eventually:

Thread Pool Exhausted
Database Connections Exhausted
Memory Increased
Application Crashes

This chain reaction is called:

Cascade Failure

3. How Circuit Breaker Prevents Cascade Failure

Circuit Breaker monitors failures.

When failures exceed a threshold:

Circuit Opens

Requests stop reaching the failing service.

Instead:

Fallback Response Returned

Example:

"Payment service unavailable. Try again later."

System remains healthy.

4. Circuit Breaker States

Resilience4J Circuit Breaker has 3 states.

          Success
     +---------------+
     |               |
     v               |
 CLOSED --------> OPEN
    ^               |
    |               |
    +---- HALF OPEN +

State 1: CLOSED

Normal operation.

Request -> Service -> Response

All requests pass through.

Example:

Payment Service -> Success

Circuit remains closed.

State 2: OPEN

Too many failures detected.

Request -> Circuit Breaker -> Fallback

No calls are sent to service.

Example:

"Payment Service Unavailable"

This protects resources.

State 3: HALF-OPEN

After waiting period:

Allow Few Requests

If successful:

OPEN -> HALF OPEN -> CLOSED

If failure continues:

OPEN -> HALF OPEN -> OPEN

8. Apply Circuit Breaker

DepartmentController.java

package com.example.controller;

import com.example.service.DepartmentService;
import io.github.resilience4j.circuitbreaker.annotation.CircuitBreaker;

import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class DepartmentController {

    private final DepartmentService service;

    public DepartmentController(DepartmentService service) {
        this.service = service;
    }

    @GetMapping("/department")
    @CircuitBreaker(
            name = "departmentService",
            fallbackMethod = "fallbackDepartment")
    public String getDepartment() {

        return service.getDepartment();
    }

    public String fallbackDepartment(Exception ex) {

        return "Department Service is currently unavailable.";
    }
}

package com.example.config;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.security.core.userdetails.*;
import org.springframework.security.crypto.password.*;
import org.springframework.security.provisioning.*;

@Configuration
public class UserConfig {

    @Bean
    public UserDetailsService userDetailsService() {

        UserDetails user =
                User.builder()
                        .username("user")
                        .password(passwordEncoder().encode("user123"))
                        .roles("USER")
                        .build();

        UserDetails admin =
                User.builder()
                        .username("admin")
                        .password(passwordEncoder().encode("admin123"))
                        .roles("ADMIN")
                        .build();

        return new InMemoryUserDetailsManager(user, admin);
    }

    @Bean
    PasswordEncoder passwordEncoder() {
        return new BCryptPasswordEncoder();
    }
}
Configure Security
package com.example.config;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

import org.springframework.security.config.annotation.web.builders.HttpSecurity;
import org.springframework.security.web.SecurityFilterChain;

@Configuration
public class SecurityConfig {

    @Bean
    SecurityFilterChain securityFilterChain(HttpSecurity http)
            throws Exception {

        http
            .authorizeHttpRequests(auth -> auth
                    .requestMatchers("/").permitAll()
                    .requestMatchers("/admin").hasRole("ADMIN")
                    .requestMatchers("/employee")
                    .hasAnyRole("USER","ADMIN")
                    .anyRequest()
                    .authenticated()
            )
            .httpBasic();

        return http.build();
    }
}

SecurityConfig.java
package com.example.config;

import java.util.List;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

import org.springframework.security.config.Customizer;
import org.springframework.security.config.annotation.web.builders.HttpSecurity;

import org.springframework.security.core.userdetails.*;
import org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder;
import org.springframework.security.crypto.password.PasswordEncoder;

import org.springframework.security.provisioning.InMemoryUserDetailsManager;
import org.springframework.security.web.SecurityFilterChain;

import org.springframework.web.cors.*;

@Configuration
public class SecurityConfig {

    @Bean
    public UserDetailsService users() {

        UserDetails user =
                User.builder()
                        .username("user")
                        .password(passwordEncoder()
                        .encode("user123"))
                        .roles("USER")
                        .build();

        UserDetails admin =
                User.builder()
                        .username("admin")
                        .password(passwordEncoder()
                        .encode("admin123"))
                        .roles("ADMIN")
                        .build();

        return new InMemoryUserDetailsManager(
                user,
                admin);
    }

    @Bean
    public PasswordEncoder passwordEncoder() {
        return new BCryptPasswordEncoder();
    }

    @Bean
    public SecurityFilterChain filterChain(
            HttpSecurity http)
            throws Exception {

        http
            .cors(Customizer.withDefaults())
            .csrf(csrf -> csrf.disable())
            .authorizeHttpRequests(auth -> auth
                    .requestMatchers("/")
                    .permitAll()

                    .requestMatchers("/admin")
                    .hasRole("ADMIN")

                    .requestMatchers("/employee")
                    .hasAnyRole("USER","ADMIN")

                    .anyRequest()
                    .authenticated()
            )
            .httpBasic(Customizer.withDefaults());

        return http.build();
    }

    @Bean
    CorsConfigurationSource corsConfigurationSource() {

        CorsConfiguration config =
                new CorsConfiguration();

        config.setAllowedOrigins(
                List.of("http://localhost:4200"));

        config.setAllowedMethods(
                List.of("GET","POST","PUT","DELETE"));

        config.setAllowedHeaders(
                List.of("*"));

        UrlBasedCorsConfigurationSource source =
                new UrlBasedCorsConfigurationSource();

        source.registerCorsConfiguration(
                "/**",
                config);

        return source;
    }
}
